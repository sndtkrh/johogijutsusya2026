# 第12回：実習2の使い方

スライドと [practice.ipynb](practice.ipynb) を使って，手書き数字を分類する．入力64，隠れ層32・16，出力10の全結合ネットワーク（MLP）で，学習曲線と誤分類を観察する．90分の授業を想定する．

## 実行方法

Google Colabにノートブックをアップロードするか，ローカルのJupyterで開く．Python 3・CPUで実行でき，GPUや有料サービスは不要．最初のコードセルは不足するライブラリだけを導入する．データはscikit-learnに含まれる1,797枚の8×8画素の画像を使う．別のダウンロードやAPIキーは不要．

ローカルの必要なライブラリは `python -m pip install -r requirements.txt` で導入できる．Jupyter自体は利用する環境に用意する．

授業では**セルごとに実行**する．8の比較実験で止まり，学習率または学習回数の一つを変える．検証結果から条件を決めた後で，9のテストへ進む．全セルの一括実行では初期設定でテストまで進む．

## 実行例

2026年10月8日，Python 3.12.14・scikit-learn 1.9.1で，全コードセルの実行を確認した．初期設定はシード42，Adam，学習率0.001，バッチ64，30エポック，L2の係数0.0001．訓練1,077件，検証360件，テスト360件．学ぶ重みとバイアスは2,778個．

| エポック | 訓練損失 | 検証損失 | 検証正解率 |
| --- | --- | --- | --- |
| 1 | 2.301 | 2.230 | 20.0％ |
| 10 | 0.963 | 0.939 | 76.4％ |
| 20 | 0.297 | 0.347 | 92.8％ |
| 30 | 0.161 | 0.229 | 94.7％ |

訓練損失は学習中のミニバッチの正則化込みの値，検証損失はエポック終了時の正則化なしの交差エントロピー．定義が厳密に同じではないため，差を単純に過学習の量とみなさない．

この設定では検証損失が最小の30エポックのコピーを選んだ．検証の誤分類は19件，最終テストは342/360件正解，正解率95.0％．この回では選んだモデルをそのまま評価し，訓練＋検証での再学習は行わない．環境や版で数値は多少変わり得る．

## 授業で提出するもの

設定と選んだエポック，曲線の読み方，誤分類の例，変更した条件の影響，最終評価の件数と指標，別の筆跡や撮影環境への限界を短くまとめる．操作が難しい場合は，講師の実行結果を使って観察と説明を行う．
