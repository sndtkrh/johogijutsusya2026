# 第11回：実習1の使い方

スライドと [practice.ipynb](practice.ipynb) を使って，アヤメの分類を実行する．90分の授業を想定する．コードを一から書くことより，学習・検証・テストの役割と比較条件を説明することを重視する．

## 実行方法

ブラウザでは，Google Colabでノートブックをアップロードして開く．Python 3・CPUの実行環境でよい．最初のコードセルは不足するライブラリだけを導入する．データはscikit-learnに含まれ，別のダウンロードやAPIキーは不要．

ローカルではJupyterで開く．必要なライブラリは `python -m pip install -r requirements.txt` で導入できる．Jupyter自体は利用する環境に用意する．

授業では**セルごとに実行**する．ノートブック6で一度止まり，特徴量または木の深さを一つ変えて，検証結果を比較する．条件を固定してから7のテストへ進む．全セルの一括実行では，初期設定でテストまで進む．

## 実行例

2026年10月8日，Python 3.12.14・scikit-learn 1.9.1で，全コードセルの実行を確認した．初期設定はシード42，特徴量4個，決定木の深さ3．

| モデル | 訓練90件の正解率 | 検証30件の正解率 |
| --- | --- | --- |
| 基準（常に一つのクラス） | 33.3％ | 33.3％ |
| ロジスティック回帰 | 97.8％ | 93.3％ |
| 決定木 | 98.9％ | 90.0％ |

検証でロジスティック回帰を選び，訓練＋検証120件で学習し直した．最終テストは28/30件正解，正解率約93.3％だった．環境や版で数値は多少変わり得る．この数値に合わせるためにテストを見て設定を変更しない．

## 授業で提出するもの

使った特徴量・モデル・設定，変更した条件と検証結果，最終評価の件数と指標，誤分類の傾向と評価の限界を短くまとめる．操作が難しい場合は，講師の実行結果を使って比較と説明を行う．

[データの出典：scikit-learn Iris dataset](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html)．説明とコードは授業用の作成物．
